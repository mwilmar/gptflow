# Tutorial GPTFlow v2.0.0

## Selamat Datang di GPTFlow! 🚀

GPTFlow adalah platform AI untuk membuat konten Instagram secara otomatis — caption, carousel, reels script, dan story. Tinggal masukkan topik, AI yang kerjakan.

---

## Menu Aplikasi

| # | Menu | Fungsi |
|---|------|--------|
| 1 | 📊 Dashboard | Overview stats & konten terbaru |
| 2 | ✨ Generate | Buat konten dengan AI |
| 3 | ✏️ Manual | Buat konten manual (field sesuai tipe) |
| 4 | 📝 Content | Lihat semua konten |
| 5 | 📅 Calendar | Jadwal posting bulanan |
| 6 | ✓ Approval | Review & approve konten (Manager/Admin) |
| 7 | 👥 Users | Kelola user & role (Admin) |
| 8 | ⚙️ Config | Setting API key pribadi |

---

## Panduan untuk Marketing Staff (Content Creator)

### Cara 1: Generate dengan AI (Menu 2)
1. Klik **2. ✨ Generate**
2. Isi topik, audiens, gaya bahasa, tipe konten
3. Gunakan **💡 Usulan AI** untuk mendapat saran di setiap field
4. Pilih gambar: **🔍 Pilih** (Unsplash) / **📁 Upload** / **🎨 Generate AI**
5. Klik **🤖 Generate Content**
6. Review hasil → klik **📤 Submit Approval**

### Cara 2: Buat Manual (Menu 3)
1. Klik **3. ✏️ Manual**
2. Pilih jenis konten → field otomatis menyesuaikan:
   - **Feed**: Caption, Hashtags, CTA
   - **Carousel**: Jumlah slide, isi per slide
   - **Reels**: Hook, Script, Durasi, Visual Direction
   - **Story**: Teks, Interaksi (Poll/Quiz/Question)
3. Gunakan **💡 Usulan AI** di setiap field
4. Pilih gambar (sama seperti Generate)
5. Klik **💾 Simpan sebagai Draft**
6. Buka **4. 📝 Content** → Submit

### Schedule Posting
1. Setelah konten di-approve, buka detail konten
2. Klik **📅 Schedule**
3. Pilih tanggal dan waktu via date/time picker
4. Konten muncul di **5. 📅 Calendar**

---

## Panduan untuk Marketing Manager

### Review & Approve (Menu 6)
1. Klik **6. ✓ Approval**
2. Lihat konten pending dari semua creator
3. Klik konten → review preview
4. **Approve** ✅ atau **Reject** ❌ + catatan revisi

### Kelola User (Menu 7, Admin only)
1. Klik **7. 👥 Users**
2. Lihat semua user terdaftar
3. Ubah role via dropdown: Creator / Manager / Admin

---

## Setting API Key (Menu 8)

1. Klik **8. ⚙️ Config**
2. Isi API key yang diperlukan:
   - **Groq** (gratis): https://console.groq.com → API Keys → Create
   - **OpenAI** (berbayar): https://platform.openai.com → API Keys → Create
   - **Instagram**: developers.facebook.com → Buat App → Instagram Graph API
3. Klik **💾 Simpan**
4. Status otomatis dicek: ✅ = valid, ❌ = belum diset/invalid

## Tips

- Topik spesifik → hasil AI lebih baik (❌ "Marketing" → ✅ "3 Kesalahan Copywriting Pemula")
- Gunakan 💡 Usulan AI — saran kontekstual berdasarkan field yang sudah diisi
- Generate gambar AI butuh OpenAI key (berbayar ~$0.04/gambar)
- Jika muncul popup error quota → top-up di dashboard provider atau ganti key di Config

## Panduan untuk Marketing Staff (Content Creator)

### Langkah 1: Generate Konten
1. Klik tombol **"+ Generate"** di dashboard
2. Isi form:
   - **Topik**: misal "Tips Public Speaking"
   - **Tipe konten**: Caption / Carousel / Reels / Story
   - **Target audiens**: misal "Mahasiswa 18-25 tahun"
   - **Gaya bahasa**: Casual / Formal / Edukatif
3. Klik **Generate** → AI buat konten dalam < 10 detik
4. Tidak puas? Klik **Regenerate** untuk versi baru

### Langkah 2: Edit & Pilih Gambar
1. Review hasil AI — edit wording jika perlu
2. Klik area gambar → pilih dari **Unsplash** (search keyword) atau **upload** dari komputer
3. Lihat **preview** seperti tampilan Instagram asli

### Langkah 3: Submit for Approval
1. Klik **Submit** → konten masuk ke queue manager
2. Status berubah jadi **Pending**
3. Tunggu manager review

### Langkah 4: Setelah Approved
1. Konten yang di-approve bisa langsung di-**schedule**
2. Pilih tanggal dan jam posting
3. Konten akan otomatis terposting di waktu yang ditentukan

### Jika Ditolak (Rejected)
1. Baca catatan revisi dari manager
2. Edit konten sesuai feedback
3. Submit ulang

## Panduan untuk Marketing Manager

### Review & Approve Konten
1. Login → lihat **Dashboard** (overview: draft, pending, approved, scheduled)
2. Klik tab **Pending** atau notifikasi
3. Buka konten → lihat preview lengkap (caption, gambar, hashtag)
4. Pilih:
   - ✅ **Approve** → konten siap di-schedule oleh staff
   - ❌ **Reject** + tulis catatan → kembali ke staff untuk revisi

### Content Calendar
1. Klik menu **Calendar**
2. Lihat jadwal posting bulanan (color-coded per tipe konten)
3. Pastikan posting konsisten (misal 3x/minggu)

## Tips untuk Member Baru 💡

Setelah register, ikuti langkah ini untuk mulai:

### 🎯 Quick Start (5 menit pertama)

1. **Coba Generate pertama** — klik "+ Generate", masukkan topik apa saja (misal "Motivasi Senin Pagi"), pilih tipe Caption, klik Generate. Lihat hasilnya!

2. **Eksplorasi tipe konten** — coba generate Carousel (dapat slide-by-slide), Reels Script (dapat narasi + visual direction), atau Story (pendek & engaging).

3. **Pilih gambar** — setelah generate, klik area gambar dan search di Unsplash. Gambar langsung muncul di preview.

4. **Submit pertama Anda** — kalau sudah puas, klik Submit. Manager akan review dan approve.

### 📝 Tips Agar Konten AI Lebih Bagus

| Tips | Contoh |
|------|--------|
| Topik spesifik lebih baik dari umum | ❌ "Marketing" → ✅ "3 Kesalahan Copywriting Pemula" |
| Sebutkan target audiens | "Mahasiswa yang baru lulus" |
| Pilih gaya bahasa yang sesuai brand | "Casual tapi profesional" |
| Tambahkan konteks jika perlu | "Untuk promo webinar minggu depan" |

### ⚡ Shortcut & Fitur Berguna

- **Regenerate** — tidak puas? Generate ulang tanpa isi form lagi
- **Preview** — lihat tampilan seperti di Instagram sebelum submit
- **Calendar** — cek jadwal tim, hindari posting bentrok
- **Edit setelah generate** — AI bukan final, selalu review dan sesuaikan

### 🔄 Workflow Singkat

```
Generate → Edit → Pilih Gambar → Submit → Approved → Schedule → Auto-Post ✓
```

## FAQ

**Q: Berapa kali bisa generate per hari?**
A: Tidak ada limit. Generate sebanyak yang dibutuhkan.

**Q: Apakah konten AI bisa langsung posting tanpa approval?**
A: Tidak. Semua konten harus melalui approval manager untuk menjaga kualitas.

**Q: Bisa edit konten setelah di-approve?**
A: Tidak. Jika perlu edit, minta manager reject dulu, lalu edit dan submit ulang.

**Q: Gambar dari Unsplash gratis?**
A: Ya, semua gambar Unsplash free to use (lisensi Unsplash).

**Q: Konten yang di-generate disimpan dimana?**
A: Semua tersimpan di dashboard Anda. Bisa diakses kapan saja.
