# Intent — GPTFlow

## Problem Statement

Sekolah training/edukasi membutuhkan konten Instagram yang konsisten, edukatif, dan engaging untuk menarik calon siswa. Namun:

1. **Inkonsistensi posting** — Tidak ada jadwal teratur, konten sporadis
2. **Waktu produksi lama** — Membuat caption, carousel, dan reels script memakan 2-4 jam/konten
3. **Kualitas tidak merata** — Tanpa framework, konten kadang bagus kadang tidak
4. **Tidak data-driven** — Tidak ada analisis engagement untuk improve konten berikutnya
5. **Manual posting** — Harus login dan posting manual setiap hari

## Business Objective

Membangun platform AI-powered yang mengotomatisasi seluruh lifecycle konten Instagram:
- **Reduce time** dari 2-4 jam menjadi 10 menit per konten
- **Increase consistency** posting 7x/minggu tanpa miss
- **Improve quality** dengan AI yang belajar dari engagement data
- **Scale** ke multi-akun tanpa tambah headcount

## Target User

| Persona | Role | Need |
|---------|------|------|
| School Manager | Decision maker | Dashboard overview, approval |
| Content Creator | Operator | Generate content, edit, schedule |
| Admin | System admin | Manage accounts, users, settings |

## Success Metrics

| Metric | Current | Target |
|--------|---------|--------|
| Posting frequency | 2-3x/minggu | 7x/minggu (1x/hari) |
| Content creation time | 2-4 jam | 10 menit |
| Engagement rate | 1-2% | 4-6% |
| Follower growth | 50/bulan | 200/bulan |
| Content approval cycle | 2 hari | 2 jam |

## Scope

### In Scope
- AI content generation (caption, carousel, reels script, story)
- Auto scheduling & posting via Instagram Graph API
- Analytics & AI recommendation
- Multi-account support
- Approval workflow
- Content calendar

### Out of Scope (v1)
- Video/image generation (hanya text/script)
- DM automation
- Comment management
- Paid ads management
